How It Works
Create a Workspace

A workspace is your main collaboration space where you organize teams and projects.

  • Create multiple workspaces for different teams or clients
  • Invite members via email or invite link
  • Manage roles (Admin / Member)
  • Control visibility (Private / Public)

Example: Marketing Team Workspace

 Create a Board

Boards represent individual projects inside a workspace.

  • Each board belongs to a workspace
  • Customize board backgrounds
  • Invite specific members to collaborate
  • Manage project-specific tasks

Example: Website Redesign Board

 Add Lists (Columns)

Lists help you structure your workflow stages.

  • Create unlimited lists
  • Rename or delete lists
  • Reorder lists by drag & drop
  • Organize tasks visually

Typical workflow: Backlog → To Do → In Progress → Review → Done

Create and Manage Tasks

Tasks (cards) represent individual pieces of work.

  • Add title and detailed description
  • Set due dates
  • Assign one or multiple members
  • Add labels (priority or category)
  • Upload attachments
  • Leave comments for collaboration

Example: “Design homepage hero section”

 Drag & Drop Workflow

Move tasks between lists to track progress visually using drag & drop.

  • Move tasks from To Do → In Progress → Done
  • Reorder tasks within a list
  • Instantly visualize project status

This follows the Kanban methodology for efficient task management.

 Assign Members & Collaborate

Collaboration keeps your team aligned and productive.

  • Assign members to tasks
  • Mention teammates in comments
  • Track responsibilities clearly
  • See who is working on what
 Search and Filter

Quickly find boards and tasks across all workspaces.

  • Global board search
  • Filter tasks by member
  • Filter by due date
  • Filter by labels
 Manage Roles & Permissions

Keep control over your workspace with role-based permissions.

  • Admins can manage members and settings
  • Admins can delete boards and workspaces
  • Members can create, edit and move tasks
  • Secure and structured collaboration
